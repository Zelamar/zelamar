# Zelamar app

Flutter client for Android and Windows (iOS and macOS later).

- `lib/` — Dart UI. `lib/src/rust/` is generated by flutter_rust_bridge, so
  never edit it by hand.
- `rust/` — `zelamar_bridge`, the thin FFI layer over `core/zelamar-core`.
  After changing anything in `rust/src/api/`, run
  `flutter_rust_bridge_codegen generate`.
- `hook/build.dart` — Native Assets hook that compiles the bridge
  ([ADR-0007](../docs/adr/0007-rust-in-flutter-via-native-assets.md)).
- `integration_test/` — end-to-end tests against the real Rust core, run on
  Windows and on an Android emulator in CI.

See the [repository README](../README.md) for setup and commands.
